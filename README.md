# تطبيق أصحاب الشبكات

تطبيق ويب بسيط (واجهة أمامية فقط) يساعد أصحاب شبكات الإنترنت المحلية على:

- إدارة الباقات وأسعارها.
- إضافة المشتركين وربطهم بالباقات.
- تسجيل التحصيلات الشهرية.
- عرض ملخص سريع لعدد المشتركين والباقات والتحصيل الشهري.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح.

> البيانات تُحفظ محليًا في `localStorage` داخل المتصفح.
